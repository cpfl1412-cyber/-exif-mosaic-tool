# 사진 안전 정리 · EXIF 삭제 + 모자이크

아이폰 사진을 **폰 밖으로 보내지 않고** 위치·기기 정보(EXIF)를 지우고, 가릴 곳을 손가락으로 문질러 모자이크/블러 처리하는 웹앱(PWA)입니다.

- 배포: https://cpfl1412-cyber.github.io/-exif-mosaic-tool/
- 서버 없음 · 업로드 없음 · 로그인 없음. 모든 처리는 브라우저(기기) 안에서만.

## 기능

1. **EXIF 감지** — JPEG의 APP1(Exif)을 클라이언트에서 직접 파싱해 GPS 위치, 카메라/폰 기종, 촬영 시각, 편집 앱, XMP 존재 여부를 배지로 알려줍니다.
2. **100% 제거 저장** — 저장할 때 캔버스에 다시 그려 `toBlob('image/jpeg')`로 새 JPEG를 만듭니다. EXIF/XMP/ICC 이외 메타데이터가 새 파일에 존재하지 않으며, 저장 후 **다시 스캔해 0건인지 검증**한 결과를 화면에 표시합니다.
3. **손가락 모자이크** — `touch-action: none` + Pointer Events. 화면 크기에 맞춰 보이는 캔버스에 원본 해상도 좌표로 매핑해 그립니다.
   - 모자이크: 원본을 블록 단위로 축소·재확대(픽셀화), 블러: `ctx.filter` 가우시안.
   - 브러시 크기 3단계, 한 단계 되돌리기, 원본 초기화.
4. **여러 장** — 여러 사진을 고르면 썸네일로 전환하며 한 장씩 처리. 저장한 사진에는 ✓ 표시.
5. **iOS 공유 시트** — `navigator.share({files})` 지원 시 공유, 미지원 시 다운로드로 대체.
6. **PWA** — 매니페스트, apple-touch-icon(180×180 실제 PNG), 오프라인 서비스 워커.

## 한계

- 아주 큰 사진은 캔버스 한계(iOS 약 1,670만 픽셀) 때문에 최대 4096px로 자동 축소해 처리합니다(화면에 표시됨).
- HEIC 원본은 브라우저가 디코딩하지 못할 수 있습니다(아이폰 사진 앱에서 JPEG로 내보내면 됨).
- EXIF 스캐너는 JPEG APP1만 읽습니다. PNG/HEIC는 "저장 시 재인코딩으로 정리" 안내만 표시합니다.
